# Student Management System

A Python-based Student Management System built as a first-year B.Tech project.

## 📌 Features

- Add student details
- Display all student details
- Search student by roll number
- Calculate average marks
- Find highest and lowest marks
- Calculate grades
- Save student details to a text file
- Menu-driven interface
- Input validation for roll numbers and marks

## 🛠️ Technologies Used

- Python
- Lists
- Functions
- Loops
- Conditional statements
- File handling
- Input validation
